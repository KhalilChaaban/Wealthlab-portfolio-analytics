What is in the folders?

wealthlab/ contains Python modules; examples/yahoo/ contains the saved report, five chart panels with AED monetary values, summary CSVs, and provenance; tests/ contains financial checks; docs/ explains the methodology.

For GitHub, use the contents of this project folder, including the updated notebook and existing README.

Historical portfolio returns are hypothetical backtest results based on market prices. Planning projections and stress scenarios are simulations. The saved summaries came from the supplied Yahoo-run notebook. Monetary figures were redrawn from those summaries; the raw daily-price cache was not attached. Re-running the notebook creates a new download and full daily exports.
